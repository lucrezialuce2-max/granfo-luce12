# Product Data Extraction for Premium Template Conversion

## Template Structure Reference
**Premium Template Format** (luminero.html):
- **Title**: SEO-optimized with product name + descriptor
- **Meta Description**: Concise value proposition
- **Tagline**: Product type (Lampada a sospensione / Lampada da tavolo / etc.)
- **Breadcrumb**: Prodotti / [Category] / [Product Name]
- **H1**: Product name (uppercase when appropriate)
- **Subtitle**: Variant/edition if applicable
- **Price Status**: "Realizzazione Artigianale su Misura"
- **Badges** (3 minimum):
  - Disponibile su richiesta
  - Consegna 4-6 settimane
  - [Custom: Lampadina non inclusa / Su misura / etc.]
- **Description**: 1-2 paragraphs describing essence
- **Tech Specs**: 4-6 rows (Diametro/Tipo/Attacco/Materiale/etc.)
- **Detail Cards**: 3 feature highlights
- **Service Badges**: 4 standard service items
- **Image Paths**: Use relative paths `images/prodotti/[Category]/[filename].webp`
