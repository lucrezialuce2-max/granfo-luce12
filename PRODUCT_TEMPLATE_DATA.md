# Premium Product Template - Data Mapping Reference

## Template Structure Overview
All products will use the **luminero.html** structure with these key sections:
- Meta tags & Schema.org structured data
- Navigation
- Product premium section (2-column layout)
- Product gallery (main image + 3 thumbnails)
- Product details (specs, badges, CTAs)
- Detail section (3 feature cards)
- Service badges section
- Footer
